Project Overview

This project is designed to continuously monitor a person’s heart rate and body temperature using sensors connected to an ESP32 microcontroller. The data is transmitted to a web dashboard in real-time, allowing for quick alerts in case of abnormal readings.

Technologies Used: ESP32, Heart Rate Sensor (Pulse Sensor), Temperature Sensor (LM35), Arduino IDE, HTML/CSS Dashboard, JavaScript.

Features

Real-Time Monitoring

Heart rate and temperature are displayed live on a web dashboard for instant observation.

Alerts and Notifications

Automatic alerts are sent if values exceed safe thresholds.

Data Logging

All readings are stored for analysis over time to detect trends or irregularities.

Easy Setup

Simple plug-and-play setup for non-technical users with minimal configuration.
